# Nautilus OS
An operating system made for your browser. Complete with everything you could possibly need to get your stuff done.

## ✨ Features
- Community Apps
- Extensive customizability
- Games
- Browsers
- Preinstalled apps
- Task manager
- Profile management
- Little achievements
- Themes
- Cloaking
- And more!
